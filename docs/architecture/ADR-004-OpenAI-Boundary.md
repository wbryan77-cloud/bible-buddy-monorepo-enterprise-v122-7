# ADR-004 — OpenAI Boundary

## Status

Accepted and permanent.

## Decision

OpenAI assists composition. OpenAI does not own truth.

OpenAI may improve warmth, clarity, naturalness, prayer wording, and
non-doctrinal companion language.

OpenAI may not determine doctrine, invent Scripture, replace canonical
retrieval, override Scripture validation, or become fallback authority for an
unresolved Scripture-owned request.

BibleBuddy's basic Scripture functionality must remain usable when OpenAI is
unavailable.
