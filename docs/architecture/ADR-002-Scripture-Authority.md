# ADR-002 — Scripture Authority

## Status

Accepted and permanent.

## Decision

Scripture owns every Scripture request.

BibleBuddy reasons from Genesis through Revelation, line upon line, precept
upon precept, and verse upon verse.

A missing semantic concept does not release a Scripture-owned request to
OpenAI.

## Valid outcomes

1. Validated Scripture-grounded answer
2. Canonical Scripture retrieval result
3. Scripture-silence determination
4. Honest Scripture retrieval failure
