# BibleBuddy Founder Alpha — Test Checklist

Twenty real-user scenarios. Check each one off as you try it — this is a
bounded, practical walkthrough, not an exhaustive technical test.

- [ ] **1. Ask for John 3:16.**
  Expect the real KJV text quoted exactly, with the reference.

- [ ] **2. Ask a doctrine question** (e.g. "Can I eat pork?" or "What is
  the Sabbath?"). Expect a direct answer grounded in cited Scripture, not
  a vague non-answer.

- [ ] **3. Ask for multiple witnesses** (e.g. "What does the Bible say
  about the Sabbath, with more than one verse?"). Expect several distinct
  supporting passages, not just one.

- [ ] **4. Ask an incorrect claim that Scripture contradicts** (e.g. "The
  Bible says Jesus had blue eyes and blond hair, right?"). Expect a clear,
  respectful correction citing the actual verse.

- [ ] **5. Ask a question Scripture does not explicitly answer** (e.g.
  "What was Jesus's favorite color?"). Expect an honest "Scripture doesn't
  say" rather than a made-up answer.

- [ ] **6. Ask an original-language question** (e.g. "What's the Greek
  word for love in John 3:16?"). Expect the original word, transliteration,
  and a plain-language explanation, clearly separated from the KJV text.

- [ ] **7. Ask for historical context** (e.g. "What was life like in
  first-century Judea?"). Expect it clearly labeled as historical/
  supplemental, not treated as Scripture.

- [ ] **8. Ask about a topic that should have extra cross-references**
  (e.g. a well-known doctrine topic). Expect at least one useful related
  passage beyond the primary verse.

- [ ] **9. Ask for prayer** ("Can you pray with me?"). Expect a genuine,
  warm prayer offer — not skipped, not forced if you decline.

- [ ] **10. Describe a hard day** ("Today has been really hard..."). Expect
  presence and warmth, not clinical distance or a canned response.

- [ ] **11. Ask for help with a personal decision** ("Should I take this
  job?"). Expect BibleBuddy to separate Scripture's clear commands from
  personal wisdom, offer practical factors, and never decide FOR you.

- [ ] **12. Correct BibleBuddy and verify recovery** (tell it it made a
  mistake, or that you meant something different). Expect it to adjust
  gracefully without getting stuck or repeating the same wrong answer.

- [ ] **13. Continue a conversation** (send a follow-up message that
  depends on what you said before). Expect it to remember the context
  within the session.

- [ ] **14. Test memory controls** (ask "what do you remember about me?"
  then "please forget that"). Expect both to work conversationally.

- [ ] **15. Paste a Bible lesson for alignment review** (Admin/Founder
  tool — ask your team lead for access if you don't have the route).
  Expect misquoted or unresolved Scripture to be flagged.

- [ ] **16. Review the Admin evidence lineage** (open the command-center
  or ask "where did that answer come from?"). Expect to see which
  authority/witnesses backed the answer.

- [ ] **17. Review an Admin candidate** (open the review queue if you have
  Admin access). Expect to see pending knowledge candidates with a clear
  reason code, and to be able to approve/reject one.

- [ ] **18. Test mobile layout.** Open the app on a phone or a narrow
  browser window. Expect the chat, input box, and buttons to remain
  usable and readable.

- [ ] **19. Trigger an external-provider fallback** (this may require
  asking the team to temporarily simulate a missing key/connection).
  Expect an honest message about the limitation, never a fabricated
  answer pretending everything is fine.

- [ ] **20. Report an issue.** Use `FounderAlphaIssueTemplate.md` for at
  least one real or simulated issue, so we confirm the reporting loop
  works end-to-end.

---

If any item behaves unexpectedly, file it using
`FounderAlphaIssueTemplate.md`. Thank you for helping test BibleBuddy!
