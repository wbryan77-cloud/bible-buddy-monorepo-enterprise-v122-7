# Admin Guide — Daily Operations (One-Admin Mode)

This is the "what do I actually do each day" guide for William R. Bryan
as the current single administrator.

## Your one daily routine

1. Open **https://bible-buddy-monorepo-enterprise-v122-7.onrender.com/admin/bible-authority.html**
2. Paste your Admin token once (it's remembered in your browser after
   that — see `AdminSecurityVerification.md` for how it's stored).
3. You land directly on the **★ Command Center** tab. Read the five
   answers at the top of Executive Overview.
4. Check the **Daily Briefing** panel (click "Today" if it isn't already
   selected). It gives you:
   - System health (requests/errors today)
   - Active users and sessions
   - Important feedback and flagged doctrine issues
   - Recent errors
   - Recurring questions
   - Response-quality concerns (fallback responses)
   - Pending decisions, broken out by severity
   - Security issues
   - A short **recommended actions today** list
5. Check **Alerts**. If anything shows Critical or High, resolve those
   first — the suggested action is shown on each alert.
6. Work the **Prioritized Decision Queue**, sorted Critical → Low. Use
   the filters if you want to focus on one category or status. Approve,
   reject, defer, or mark items investigating/resolved directly from the
   table.
7. If you're not sure what matters most, ask the **AI Chief of Staff**:
   "What needs my attention today?"
8. Use the **search bar** any time you remember a topic, Scripture
   reference, or session but not which tab it lives in.

## What "no urgent items" means

If the Daily Briefing's recommended-actions list says "No urgent items.
Routine review recommended," that's an honest signal computed from zero
Critical alerts and zero High-severity queue items right now — not a
placeholder. Use that time for routine review of the Decision Queue and
the specialized tabs (Scripture Authority Review, Founder Intelligence,
etc.).

## Everything else stays exactly where it was

The Command Center does not remove any existing tab. Executive Growth,
Scripture Authority Review, Engineering Intelligence, Founder Readiness,
and Founder Intelligence are all still there, unchanged, one click away
from the nav bar or from any "drill down →" link in the Command Center.
