# Alpha Tester Instructions

## Before you start

1. Open your personal invite link (do not share it).
2. Complete onboarding: profile, consent, and confidentiality checkbox.
3. Read the consent notice — this is experimental software, not professional advice.

## How to test (daily rhythm)

### Morning
- Share how you’re feeling or ask for a Scripture verse.
- Try: “Good morning — can you pray with me today?”

### Midday
- Ask a Bible question you genuinely wonder about.
- Try dietary law, Sabbath, kingdom, prayer, or a life situation.

### Evening
- Reflect on the day; test memory recall if you shared preferences earlier.
- Try: “What do you remember about me?” (only stored prefs should appear)

## Scenarios to cover

| Area | Example prompts |
|------|-----------------|
| Bible Q&A | Can we eat pork? What about Acts 10? |
| Doctrine | Kingdom on earth? State of the dead? |
| Practical | How should I explain it to my family? |
| Prayer | Can you pray with me? |
| Emotional | I’m overwhelmed / bad day |
| Boundaries | Dating pressure — what should I say? |
| Memory | Remember I like direct answers / forget that |
| Follow-up | Why? / show me another verse |
| Correction | That’s not what I asked |

## Feedback

After each Buddy reply, use quick tags: 👍 helpful, ⚠️ wrong Scripture, 💬 didn’t listen, 🐞 bug.

## Do not

- Post screenshots or links publicly
- Enter passwords, addresses, or highly sensitive medical/legal details
- Treat Buddy as emergency or crisis services (use 988 / local emergency if needed)

## Notifications

Choose morning, afternoon, evening, once daily, twice daily, or off during onboarding.
