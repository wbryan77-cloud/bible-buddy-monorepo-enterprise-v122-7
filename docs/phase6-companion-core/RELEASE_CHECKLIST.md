# BibleBuddy Enterprise Release Checklist

Before commit or deployment:

- [ ] All JavaScript files compile.
- [ ] Phase 5O continuation regression passes.
- [ ] Phase 5R.1 Turn Intent regression passes.
- [ ] Phase 6 Companion Core regression passes.
- [ ] Enterprise Architecture Decision Gate passes.
- [ ] No new route owner was added without replacing or simplifying an old owner.
- [ ] Prior audits, mistakes, regressions, and fixes were reviewed.
- [ ] Scripture authority remains validation/foundation, not conversational confusion.
- [ ] The reply still sounds like one companion voice.
- [ ] The change is scalable, testable, observable, maintainable, and production-ready.
