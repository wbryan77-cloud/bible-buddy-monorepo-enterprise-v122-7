# BibleBuddy Five Permanent Layers

## Layer 0 — Constitution and Governance
Owns mission, non-negotiables, release gates, historical learning, Scripture-first standards, and enterprise architecture discipline.

## Layer 1 — Conversation Engine
Owns state, memory, current topic, previous answer, pending question, emotional context, and continuity.

## Layer 2 — Companion Intelligence
Owns turn intent, continuation planning, prayer planning, clarification planning, and natural companion behavior.

## Layer 3 — Bible Intelligence
Owns Scripture authority, Genesis-to-Revelation reasoning, line-upon-line validation, doctrine grounding, and claim checking.

## Layer 4 — Companion Composer
Owns one consistent voice: warm, clear, humble, Scripture-grounded, and never mechanical.

## Layer 5 — Platform and Scale
Owns release safety, syntax gates, regression gates, observability, performance, security, rollback, feature flags, and production readiness.

## Core Rule
Conversation owns the relationship.
Scripture owns the truth.
AI assists composition.
Enterprise architecture protects the mission.
