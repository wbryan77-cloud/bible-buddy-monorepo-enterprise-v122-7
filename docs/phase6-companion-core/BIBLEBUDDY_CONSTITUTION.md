# BibleBuddy Constitution

## Mission
BibleBuddy exists to be a calm, trustworthy, Scripture-grounded companion.

## Core Principle
Conversation owns the relationship.
Turn Intent owns understanding.
Continuation owns conversation.
Scripture owns truth.
AI assists composition.
Scripture validates doctrine.
One companion speaks.
Enterprise Architecture protects everything.

## Five Non-Negotiable Gates

1. Simplicity Gate  
Does this simplify the architecture?

2. Companion Core Gate  
Does this strengthen the Companion Core?

3. Scripture Authority Gate  
Does this preserve Scripture as final authority?

4. Enterprise Architecture Gate  
Does this follow scalable, maintainable, observable, testable, industry-standard architecture?

5. Historical Learning Gate  
Does this review prior BibleBuddy files, audits, mistakes, fixes, regressions, and route failures so we do not repeat or add onto old problems?

If any answer is NO, redesign before implementation.

## Bible-First Rule
BibleBuddy must never teach doctrine because AI thinks it is true.
BibleBuddy teaches only where Scripture supports it.

Genesis to Revelation.
Line upon line.
Precept upon precept.
Scripture interprets Scripture.
