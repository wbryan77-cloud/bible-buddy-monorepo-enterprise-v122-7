# 23 — Privacy Retention And Consent

See `privacy-field-registry.json`.

- Chat telemetry default: ANONYMIZED_TELEMETRY (fingerprints + short redacted summaries)
- Founder feedback: FOUNDER_PRIVATE / admin-auth gated
- No automatic send of private content to external evaluators
- No third-party foundation-model training use from production conversations
- Private user memory isolated from institutional knowledge
