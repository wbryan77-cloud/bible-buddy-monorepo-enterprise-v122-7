# Storytelling Pattern Library (Transferable Mechanics Only)

**Purpose:** Reusable story *engineering* for BookBuddy.  
**Hard rule:** No copyrighted plots, anecdotes, character biographies, or distinctive scene reproductions from the seven benchmarks (or any copyrighted source). Patterns below are structural abstractions.

**Related:** `SevenBestsellerCraftSynthesis.md`, `HumanConnectionScorecard.md`, per-book profiles.

---

## How to use this library

For each major teaching unit, pick **one primary pattern** + optional **micro-pattern**. Fill with **original** observation, composite (clearly framed), historical public-domain material, or reader-safe hypotheticals. Then run the house movement:

**LIFE → PAIN → QUESTION → DISCOVERY → SCRIPTURE → UNDERSTANDING → ACTION → CHANGE**

---

## A. Opening patterns

### A1. Stakes cold-open
- **Mechanic:** Begin mid-problem with sensory concreteness; delay interpretation.  
- **Best for:** Habit, fear, conflict, sudden loss of control.  
- **Risk:** Melodrama; keep short.  
- **Exit into teaching:** One sentence naming the universal tension.

### A2. Dual-voice contrast
- **Mechanic:** Two advisors / two instincts / two futures argue through the protagonist’s choice.  
- **Best for:** Worldview forks, money, priority, identity.  
- **Risk:** Caricaturing one side; keep charity.  
- **Exit:** Diagram or named dichotomy.

### A3. Crowd-desire mirror
- **Mechanic:** Show many people wanting the same skill/relief; reader feels less alone.  
- **Best for:** “I’m not the only one who…” introductions.  
- **Risk:** Hype rally tone — avoid.

### A4. Map-before-journey
- **Mechanic:** Almost anti-story: show the terrain, icons, and permission to explore.  
- **Best for:** Orientation chapters, canon tours, “how to read this book.”  
- **Risk:** Dryness — add one human reason the map matters.

### A5. Earned-silence open
- **Mechanic:** Gravitas first; no benefit laundry list; reader enters a serious room.  
- **Best for:** Suffering, lament, meaning, repentance.  
- **Risk:** Heaviness without hope path — always hinge to meaning/Scripture carefully.  
- **Ban:** Using extreme trauma detail from others’ lives as hooks.

## B. Story ↔ teaching alternation

### B1. Pearl string (short proofs)
- **Mechanic:** Principle stated → 2–4 miniature scenes → principle restated (“nutshell”).  
- **Best for:** Relational skills, micro-obedience, speech ethics.  
- **Length:** 3–8 sentences each pearl.

### B2. Keystone case (one long vehicle)
- **Mechanic:** Single case carries the whole chapter; science/theology inserts as “decoder” beats.  
- **Best for:** Complex mechanisms (loops, institutions, multi-step repentance).  
- **Rule:** Crystallize the model by the 40–60% mark; don’t save the point for the last paragraph only.

### B3. Mosaic witness
- **Mechanic:** Many observational shards → slow crystallization of one hard truth.  
- **Best for:** Suffering, community, formation over time.  
- **Rule:** Prefer original pastoral composites; never mine atrocity narratives.

### B4. Failure lab
- **Mechanic:** Attempt A fails → Attempt B fails → Attempt C reveals the missing lever.  
- **Best for:** Habit change, prayer consistency, reconciliation.  
- **Maps to:** “Golden middle” idea — keep cue/desire, change routine (abstracted).

### B5. Identity mirror
- **Mechanic:** Character acts from “I am the kind of person who…”; plot shows identity locking behavior.  
- **Best for:** Habit, holiness, courage.  
- **Exit:** Invite new identity claims grounded in Scripture (not pep talk).

## C. Wound / desire / stakes kit (fill blanks; don’t copy sources)

Use this checklist when drafting an original story beat:

| Field | Prompt |
|---|---|
| Wound | What already hurts? |
| Desire | What do they want on the surface? |
| Deeper desire | What do they want underneath? |
| Misconception | What false map are they using? |
| Immediate problem | What breaks *today*? |
| Stakes | What do they lose if nothing changes? |
| Shame / fear / hope | Which emotion leads? |
| Turn | What forces a reframe? |
| Principle timing | Before, during, or after the turn? |
| Scripture hinge | What question sends them to the text? |
| Landing | What feeling should remain? |
| Action | What is doable within 7 days? |

## D. POV & distance presets

- **Close first-person (sparingly):** solidarity, confession of a common failure.  
- **Close third:** default for scenes.  
- **Reported guide:** interviewer/teacher voice for research-like chapters.  
- **Parable distance:** clearly framed illustrative fiction; don’t fake memoir.

---

## E. Dialogue mechanics (not content)

- Wrong-move line vs right-move line (show, don’t lecture).  
- Mentor question > mentor speech.  
- Interrupt advice with listening beats.  
- Keep dialogue short; let silence teach.

---

## F. Humor & surprise (safe dials)

- **Recognition humor:** “I’ve done that exact useless thing.”  
- **Reversal:** expected spiritual answer fails because motive was wrong.  
- **Scale shift:** tiny cue → huge life drift (compounding pattern).  
- **Avoid:** sarcasm at sufferers; jokes that shrink Scripture; punchlines that need copyrighted setups.

---

## G. Sensory & concrete detail (pattern)

- One object, one place, one bodily tell (hands, sleep, phone, kitchen table).  
- Prefer ordinary life arenas: commute, inbox, dinner, church foyer, late-night scroll.  
- Specificity creates trust; inventory dumps create noise.

---

## H. Return & callback patterns

- Reintroduce an opening object at the chapter end (transformed meaning).  
- Recycle a framework name across chapters (vocabulary loyalty).  
- “Last time we named X; today it fails in public” (Private → Public victory sequencing, abstracted).

## I. Chapter exit patterns

| Exit type | Mechanic | Use when |
|---|---|---|
| Checklist | 3 bullets “do this” | Skills, habits |
| Nutshell card | Numbered rules | Relational practice |
| Reflection question | One deep ask | Meaning, conviction |
| Diagram redraw | “Sketch from memory” | Framework chapters |
| Map pin | “Next go to…” | Orientation / survey |
| Silence landing | Short final sentence; no pep | Lament, awe |

---

## J. Anti-patterns (do not do)

- Stacking five anecdotes where one keystone suffices.  
- Teaching interrupting every paragraph of a story (whiplash).  
- Stories that only flatter the teacher.  
- Borrowed “famous” plots lightly rewritten (still infringement risk + laziness).  
- Trauma exhibition.  
- Manipulation stories that teach winning over loving.

## L. Copyright-use reminder

If a pattern was *noticed* in a bestseller, the deliverable must still be **original scenes and wording**. When in doubt: new characters, new stakes, new details, same *mechanic*.
