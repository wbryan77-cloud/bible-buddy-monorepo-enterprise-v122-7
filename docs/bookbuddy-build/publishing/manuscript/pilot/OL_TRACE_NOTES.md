## 1. Philippians 4:6 — *merimnaō* (anxious care)

| Step | Content |
|---|---|
| **Primary text path** | `data/original-language/greek/raw/Nestle1904.csv` → BCV `Phil 4:6` |
| **Form** | μεριμνᾶτε (*merimnate*) |
| **Lemma** | μεριμνάω (*merimnaō*), Strong’s **G3309** |
| **Morphology** | V-PAM-2P (present imperative, 2nd plural) with μηδὲν |
| **Gloss (Strong’s)** | to be anxious about; KJV range: be careful / take thought |
| **Plain English** | do not let anxious / fretting care pull you apart; do not be over-occupied with worry |
| **KJV** | “Be careful for nothing…” |
| **Used in** | `01_Mind_Purpose_FULL.md` (also noted via Matt 6:34 same lemma) |
| **Limit** | Does **not** mean emotions are sin, or that clinical care is unspiritual. Alternative in context is prayer + petition + thanksgiving + specific requests (*αἰτήματα*, G155), not numbness. |

**Related (same chapter):** Phil 4:7 *φρουρήσει* ← *φρουρέω* (G5432) — “shall keep” as garrison/guard. Supports “peace as sentinel,” not “peace as mood product.”
