# BookBuddy — Book Series Design Bible

**Date:** 2026-08-29  
**Scope:** Volume 1 + future companions (C1–C4) and later volumes  
**Path:** `docs/bookbuddy-build/publishing/design/BookBuddy_BookSeriesDesignBible.md`

---

## Purpose

One house system that stays recognizable across books while allowing each volume’s emotional individuality.

---

## SERIES-CONSTANT (keep stable)

| Element | Constant |
|---|---|
| Typography family | Same body/title pairing across volumes (once locked) |
| Scripture logic | KJV controlling; block grammar; boxes rare |
| Navigation | Contents + running heads + chapter numbers |
| Note system | Endnotes preferred; no internal QA leakage |
| Basic grid | Same trim family + margin philosophy |
| Series identity | Quiet wordmark/title-page presence — not sticker on every page |
| Story immersion rule | Story-first openers; no chrome on first story pages |
| Callout minimalism | Small shared vocabulary |
| Immutability | Frozen manuscript ≠ design copy |
| Ending rule | Complete promise → human aftershock → doorway (from SeriesBible) — design never turns doorway into catalog |

---

## VOLUME-VARIABLE (may change)

| Element | May vary |
|---|---|
| Accent (if color edition) | Per-volume muted accent — never rainbow coding |
| Emotional density / white space | Grief volumes quieter (C3); practical volumes slightly denser |
| Chapter imagery | Default none; only with Founder approval |
| Specific callouts | Volume may emphasize different scarce devices |
| Pace | Act structure may differ; visual rhythm follows emotion |
| Visual atmosphere | Same fonts; different spacing/frequency |
| Diagram count | Per-volume need |

---

## Volume emotional notes (design)

| Volume | Atmosphere hint |
|---|---|
| V1 Flagship | Hybrid literary-practical; full arc |
| C1 Money | Stewardship clarity; kitchen-table humanity |
| C2 Relationships | Dignity; door metaphor continuity if earned |
| C3 When Life Hurts | **Quietest** system; Lena-grade restraint as baseline |
| C4 Who Is God? | Wonder + landmark air; anti-textbook |
