# Volume 1 — Phase 2 Prototype Specification

**Date:** 2026-08-29  
**Authorization:** Requires Founder + ChatGPT Phase 1 review first.  
**Output:** Rendered pages (PDF proofs), not full book.

---

## Global Phase 2 brief

1. Produce **at least two design directions** initially (recommend: Direction C Hybrid as primary; Direction A Literary as foil).  
2. Typeset **only** prototype chapters A–D (ch00, ch06, ch08, ch12).  
3. Use derived text from frozen manuscript — no wording “improvements.”  
4. Grayscale-first.  
5. Compare side-by-side for Founder.

## Comparison requirements

For each chapter, Founder receives:

- Direction C pages  
- Direction A pages (same text)  
- One-page designer note: density, Scripture, callouts used  
- QA scores against Design QA Matrix (target: no dimension below 90 — do not inflate)
