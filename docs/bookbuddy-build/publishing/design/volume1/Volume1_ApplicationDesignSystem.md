# Volume 1 — Application Design System

**Date:** 2026-08-29  
**Goal:** Practical without corporate training, productivity-app, homework, or church-worksheet aesthetics.

---

## Hierarchy of application forms

| Form | When to use |
|---|---|
| **Prose (default)** | Most “Monday morning” counsel |
| Short numbered steps (3–5) | When order matters and manuscript already numbers |
| Short bullets | Parallel options; keep ≤5 |
| Checklist | **Rare** — only if manuscript is already checklist-like; no empty checkbox UI required |
| Simple framework / named frame | Steward’s table, Keepable Rule, Monday Mercy hinges |
| Sidebar | Optional demotion of secondary tips — Phase 2 trial |
| Table | Only when comparison is clearer than prose (see Table audit) |

---

## Time horizons (visual weight)

| Horizon | Weight |
|---|---|
| Immediate / today | Highest among practices — still prose-first |
| 24–48h | Medium |
| 72h | Medium |
| Weekly / Keepable Rule | Artifact once (ch10) |
| Habits / decision frameworks | Named frame once per chapter max |
| Relationship / money / prayer practices | Stay in chapter voice; do not create icon rows |

Do **not** invent a running icon system for “24h / 72h / week.”

## Monday sections

- Heading may use consistent small-caps / section style.
- Content remains pastoral.
- Avoid progress rings, habit streak UI, or QR codes.

## Anti-patterns

- Corporate SMART-goal templates  
- App-like cards every chapter  
- Homework lines / ruled journal pages  
- Rainbow priority tags  

## Success test

Application feels like wise counsel after discovery — not a curriculum packet.
