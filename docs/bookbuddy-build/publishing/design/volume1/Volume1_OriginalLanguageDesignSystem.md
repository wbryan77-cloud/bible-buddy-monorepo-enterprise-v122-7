# Volume 1 — Original-Language Design System

**Date:** 2026-08-29  
**Goal:** “That helps me understand the Bible.” — not “I just entered seminary.”

OL appears selectively in the frozen manuscript (Nestle 1904 Greek; OSHB Hebrew). Design must illuminate, not intimidate.

---

## Content elements that may appear

| Element | Default placement |
|---|---|
| Hebrew / Greek script | MAIN TEXT inside short “What the word actually says” section |
| Transliteration | Immediately beside script (*ḥesed*, *merimnaō*) |
| Lemma + gloss | Same paragraph; one sentence |
| Semantic explanation | Plain English next sentence |
| KJV comparison | Already in manuscript flow — keep adjacent |
| Strong’s / G#### / H#### | Acceptable in main text if manuscript has them; visually demote (same size, no badge) |
| Morphology dumps | **Avoid elevating**; if present, do not table-ize |

---

## Presentation grammar (RECOMMENDED)

1. **Short discovery inset** — not a lab card.
2. Same body font; Greek/Hebrew in capable faces (see Typography Strategy).
3. Script + transliteration + one gloss line maximum as visual cluster.
4. Explanation continues in normal prose.
5. No giant language tables.
6. No “Word Study Worksheet” chrome.
7. ch07 already teaches beginners need not know OL to begin — design must honor that.

### Optional secondary placements

| Placement | When |
|---|---|
| SIDEBAR | Only if main-text inset crowds a page *and* Founder approves Phase 2 trial |
| FOOTNOTE | Technical source notes (Nestle 1904 / OSHB) if front matter promises notes |
| ENDNOTE | Prefer for repeated apparatus if print density demands |
| APPENDIX | Glossary of load-bearing words (optional back matter) — not required for V1 |

**RECOMMENDED for V1 print:** keep OL in main text as manuscript does; demote visually; optional endnote apparatus for edition statements only.

---

## Load-bearing wonder moments (protect)

| Passage | Treatment |
|---|---|
| Phil 4 *phroureō* / sentinel (ch01) | Discovery inset + air; pull-quote candidate is the English metaphor, not Greek |
| Exod 34 *ḥesed* (ch08) | Maximum dignity; space; do not bury in table |
| Heb 4 *parrēsia* (ch09) | Soft inset after long KJV block |
| Gal 5 *stoicheō* (ch12) | Guardrail tone — practical, not academic |

## Anti-patterns

- Lexicon-card overload  
- Color-coded Hebrew/Greek  
- Interlinear sprawl  
- Strong’s numbers as badges/icons  
- Separate “Seminary Corner” brand

## Success test

A Reader A (rarely reads Bible) can skip the script glyphs and still get the English discovery. A Reader B still gets the linguistic precision without a costume change into textbook.
