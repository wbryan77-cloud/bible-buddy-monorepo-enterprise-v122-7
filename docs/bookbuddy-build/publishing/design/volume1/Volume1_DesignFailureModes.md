# Volume 1 — Design Failure Modes (Red Flags)

**Date:** 2026-08-29  

Watch for and reject:

1. AI-looking layout (generic gradients, uneven card grids, stock “template book”)  
2. Too many boxes  
3. Too many icons  
4. Too many heading levels shouting at once  
5. Scripture visual overload (every verse boxed/highlighted)  
6. Excessive bold  
7. Excessive italics  
8. Giant pull quotes as default  
9. Tiny body text  
10. Narrow margins  
11. Dense pages without emotional reason  
12. Overly sparse pages (poseur emptiness)  
13. Workbook feel  
14. Sermon handout feel  
15. Academic feel  
16. Generic Christian publishing clichés  
17. Generic self-help clichés  
18. Inconsistent Hebrew/Greek rendering  
19. Poor ebook conversion (text-as-image, broken tables)  
20. Decorative clutter  
21. Visual monotony (every spread identical tip card)  
22. Visual novelty without function  
23. Grief commercialization (ch06)  
24. Companion product grid on literary last spread  
25. Act labels printed without Founder approval  
26. Benchmark trade-dress resemblance  
27. Silent frozen-manuscript edits for layout convenience  

**Prototype gate:** any red flag on ch00/ch06/ch08/ch12 = direction fails regardless of “pretty.”
