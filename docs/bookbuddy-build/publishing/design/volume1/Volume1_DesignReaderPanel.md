# Volume 1 — Design Reader Panel

**Date:** 2026-08-29  
**Method:** Design-intent panel (not live user test). Five reader lenses against Phase 1 system.

---

## READER A — Believer who rarely reads the Bible

| Lens | Assessment |
|---|---|
| INVITES | Maya grocery entry; low-Scripture ch00; Camila beginner door |
| INTIMIDATES | Nested OL with Greek script; stacked G2R landmarks |
| TOO RELIGIOUS | Verse boxes + praying-hands ornaments (we ban) |
| TOO SELF-HELP | Habit cards / streak energy (we restrain) |
| TOO ACADEMIC | Morphology dumps (we demote) |
| SCRIPTURE ACCESS | Indented KJV with air; English discovery before glyphs |
| CONTINUATION | Story returns; Monday mercy without shame |
| ABANDONMENT RISK | ch08 density — needs breathing room prototype |

## READER B — Regular Bible reader

| Lens | Assessment |
|---|---|
| INVITES | Context-first KJV; G2R honesty; OL precision |
| INTIMIDATES | Little — unless design looks unserious |
| TOO RELIGIOUS | Saccharine graphics |
| TOO SELF-HELP | Thin proof-texting look |
| TOO ACADEMIC | Fine if OL stays short |
| SCRIPTURE ACCESS | Already high; wants dignity not gimmick |
| CONTINUATION | Owen wonder; Lena theological honesty |
| ABANDONMENT RISK | Workbook furniture shouting over exegesis |

## READER C — Hurting / confused

| Lens | Assessment |
|---|---|
| INVITES | Lena quiet pages; honest hope; no “fix it” chrome |
| INTIMIDATES | Dense tables beside grief; bright callouts |
| TOO RELIGIOUS | Slogan-verse stickers (manuscript already critiques) |
| TOO SELF-HELP | Resilience posters |
| TOO ACADEMIC | Irrelevant in ch06 if we keep OL out |
| SCRIPTURE ACCESS | Job 2:13 with space; long Romans as expanse not dump |
| CONTINUATION | Felt dignity |
| ABANDONMENT RISK | Designing grief like a product feature |

## READER D — Skeptical but curious

| Lens | Assessment |
|---|---|
| INVITES | Human stories; “what this does not mean”; anti-hustle honesty |
| INTIMIDATES | Churchy ornament; altar-call layout |
| TOO RELIGIOUS | Cross wallpaper; gold verse cards |
| TOO SELF-HELP | Guru certainty design |
| TOO ACADEMIC | Seminary deckle |
| SCRIPTURE ACCESS | Clear KJV as primary text — can argue with it |
| CONTINUATION | Authority order transparency |
| ABANDONMENT RISK | Looking like propaganda pamphlet |

## READER E — Modern personal-development reader

| Lens | Assessment |
|---|---|
| INVITES | Keepable Rule clarity; next inch; Monday Mercy |
| INTIMIDATES | Long Scripture chains without navigation |
| TOO RELIGIOUS | Liturgical costume |
| TOO SELF-HELP | If we over-card — uncanny valley of every habit book |
| TOO ACADEMIC | OL walls |
| SCRIPTURE ACCESS | Needs English payoff obvious |
| CONTINUATION | Practical frames with theological spine |
| ABANDONMENT RISK | Either pure sermon handout *or* pure Atomic-clone |

---

## Design implication

Hybrid Direction C must satisfy A–E by **restraint**: literary enough for B/D, practical enough for E, gentle enough for C, accessible enough for A.
