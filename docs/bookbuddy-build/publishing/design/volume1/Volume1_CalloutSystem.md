# Volume 1 — Callout System

**Date:** 2026-08-29  
**Target:** Minimalism. Every type has a semantic function. Never box for boredom.

---

## Recommended vocabulary (4 types — not 6)

| Type | Function | Frequency |
|---|---|---|
| **SCRIPTURE DISCOVERY** | Rare key passage emphasis when space alone is insufficient | 0–2 / chapter; 0 in ch06 default |
| **KEY IDEA** | Named frames (Beloved before brand, Monday Mercy, etc.) | ≤1 / chapter |
| **REFLECTION** | Single question or prayer invitation | ≤1 / chapter; 0 in ch06 |
| **ORIGINAL-LANGUAGE INSIGHT** | Only if main-text OL needs demotion — prefer main text | Rare |

### Not recommended as separate types (V1)

| Rejected | Why |
|---|---|
| PRACTICE as distinct chrome | Fold into Key Idea or Monday prose |
| WARNING / MISUNDERSTANDING box | “What this does not mean” is already an H2 — typography enough |

**RECOMMENDED_CALLOUT_COUNT (types):** **4 maximum; ship with 3 if OL stays in body.**

---

## Visual rules

- One style family; differentiate by label + spacing, not five border personalities  
- Prefer left rule or top hairline over heavy fill  
- Grayscale-first; tint only if print color edition exists and contrast passes  
- No icons  
- No rounded “app cards”  
- ch06: **callout ban** except possibly ultra-soft Honest hope — default none  

## Anti-patterns

- Tip boxes every spread  
- Pull-quote + callout + table on same page  
- Callout repeating the heading above it  

## Success test

Callouts feel earned. Removing any one would lose navigation — not decoration.
