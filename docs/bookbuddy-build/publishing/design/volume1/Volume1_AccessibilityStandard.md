# Volume 1 — Accessibility Standard

**Date:** 2026-08-29  

---

## Print

| Spec | Standard |
|---|---|
| Body size | ≥10 pt at 6×9; prefer 10.5–11.5 |
| Contrast | Near-black on white; gray text only for folios/captions with strong contrast |
| Line length | ~60–70 characters |
| Heading hierarchy | Semantic and visual; no skipped levels for decoration |
| Italics | Limited; not whole sections |
| ALL CAPS | Short labels only |
| Color | Never sole meaning carrier |
| Footnote size | ≥8 pt equivalent if used |
| Tables | Clear headers; not image-only |

## Ebook / reflow

| Spec | Standard |
|---|---|
| Semantic HTML headings | h1 chapter, h2 sections |
| Reading order | Linear; no float puzzles |
| Scripture blocks | `blockquote` or styled paragraph — not text-as-image |
| Hebrew/Greek | Real Unicode; not pictures of glyphs |
| Tables | Responsive / stacked fallback |
| Reflection spacing | CSS margins, not empty Unicode spam |
| Screen readers | Meaningful alt only if images exist (default: none) |

## Cognitive accessibility

- Avoid clutter that raises fatigue (callout spam)  
- ch06 quietude helps distressed readers  
- OL skippable without losing main claim  

## Success test

Readable when tired. Navigable by screen reader in EPUB.
