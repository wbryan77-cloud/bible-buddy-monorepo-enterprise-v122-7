## Book-wide table grammar (if used)

- 2 columns max preferred  
- Header row in small caps or subtle bold  
- No shaded zebra unless accessibility requires  
- No icons in cells  
- Prefer top-aligned; generous cell padding  
- Ebook: convert wide tables to stacked definition lists if needed
