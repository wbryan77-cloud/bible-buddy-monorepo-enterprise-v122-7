# Volume 1 — Typography Strategy

**Date:** 2026-08-29  
**Personality:** warm · human · intelligent · trustworthy · contemporary · timeless · accessible · serious · hopeful  
**Not:** corporate · startup · luxury-fashion · children’s devotional · academic textbook · church newsletter · motivational poster · AI report

**Licenses:** Do not lock commercial fonts yet. Characteristics + candidates only.

---

## Role recommendations

| Role | Recommendation |
|---|---|
| BODY | **Serif** — excellent long-form; warm, not chilly Didone; not chunky slab |
| CHAPTER TITLES | Serif display or restrained sans; literary, not poster |
| SECTION H2 | Small caps **or** semibold sans/serif smaller than chapter; consistent |
| SUBHEADS H3 | Quieter; title case; avoid ALL CAPS paragraphs |
| SCRIPTURE | Same family as body (roman or italic block); not costume Blackletter |
| PULL QUOTES | Same family, larger; scarce |
| REFLECTION | Body or slight size change; minimal |
| CAPTIONS | Sans or small serif; rare (few figures) |
| FOOTNOTES | 8–9 pt equivalent; readable |
| ENDNOTES | Same |
| PAGE NUMBERS | Quiet; folio centered or outer |
| RUNNING HEADS | Short title / chapter title; small; not shouty |

**RECOMMENDED body character:** warm transitional or humanistic serif suitable for 10–11.5 pt at 6×9.

### Title / sans companions
| Family | Notes |
|---|---|
| Source Sans 3 | Clean companion to Source Serif |
| IBM Plex Sans | Human, not startup-neon |
| Atkinson Hyperlegible | Accessibility-forward for UI bits only — not whole body |

### Scripture / OL
- Prefer body family with Greek + combining marks.
- Hebrew: may require a dedicated Hebrew-capable face for script runs; keep size matched to body.
- **EXTERNAL_VERIFICATION_REQUIRED:** final stack must render Nestle Greek + OSHB Hebrew cleanly in print + EPUB.

## Size / rhythm starting points (6×9 — provisional)

| Element | Start |
|---|---|
| Body | 10.5–11.5 pt |
| Leading | 14–16 pt (~1.3–1.4) |
| Chapter title | 18–24 pt |
| H2 | 11–13 pt small caps or 12–13 semibold |
| Scripture block | body or −0.5 pt; leading +1–2 |
| Folio | 9–10 pt |

Exact values → Phase 2 prototype.

## Policies

- **Italics:** for emphasis, thoughts, transliteration — not whole teaching sections  
- **Bold:** rare; headings and scarce frames only  
- **ALL CAPS:** short labels only (if any); never long sentences  
- **Small caps:** excellent for H2 furniture to reduce “workbook shout”
