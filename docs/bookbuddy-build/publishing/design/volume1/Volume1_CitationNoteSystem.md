# Volume 1 — Citation & Note System

**Date:** 2026-08-29  
**Reader-facing book must not expose:** BookBuddy IDs, governance labels, corpus paths, QA codes, evidence classifications, development terminology.

---

## Scripture citations

- KJV references in-text as manuscript: `(Book ch:v, KJV)` or equivalent already used  
- First-use translation statement in front matter  
- No invented alternate translations as authority  

## Historical / modern sources

- Only if manuscript already attributes  
- No invented citations  
- Secondary wisdom stays clearly non-Scripture (ch00 authority order)

## Original-language sourcing

- Short edition note: Hebrew text referenced via OSHB; Greek via Nestle 1904, as manuscript states  
- Strong’s numbers may remain where manuscript has them; do not expand into lexicon essays in notes  

## Note architecture (RECOMMENDED)

| Layer | Use |
|---|---|
| In-text | Scripture + light OL |
| Endnotes | Optional apparatus, permissions, edition notes |
| Bibliography / source notes | Only if Founder requires; keep short |
| Footnotes | Discouraged for V1 — protect page rhythm |

## Stripping for production

Derived production files should remove any residual internal markers if present (IDs, gate codes). **Do not** alter doctrinal wording while stripping.

## Success test

A bookstore browser sees a normal trade book — not an internal certification packet.
