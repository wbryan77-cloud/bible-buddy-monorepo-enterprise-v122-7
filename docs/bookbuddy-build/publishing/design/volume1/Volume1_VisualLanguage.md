# Volume 1 — Visual Language (Ornament / Icon Policy)

**Date:** 2026-08-29  
**Default:** LESS IS MORE.

---

## Icons

**RECOMMENDED:** **No icons** in Volume 1 interior.

Explicitly avoid: lightbulb, brain, moneybag, heart, praying hands, crosses everywhere, generic AI iconography, emoji.

## Ornaments / rules / glyphs

| Element | Policy |
|---|---|
| Scene break | Blank line preferred; optional single centered hairline or simple typographic asterisk — one book-wide choice |
| Chapter opener | No flourish stack; optional single thin rule under title |
| Section | Hairline rare (G2R / named frame) |
| Chapter mark | Number + title enough; no monogram required for V1 |
| Series mark | Reserve for title page / cover — not every chapter |

If ornaments exist, they must feel **editorial and timeless**, not sticker-pack.

## CHANGE/MAKER (ch11)

Treat as **typographic foil** (weight/spacing), not a logo system.

## Success test

Flip test: pages do not look “designed with an icon set.”
