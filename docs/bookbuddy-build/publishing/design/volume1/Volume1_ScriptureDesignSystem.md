# Volume 1 — Scripture Design System

**Date:** 2026-08-29  
**Authority:** KJV controlling for reader-facing Scripture.  
**Goal:** Scripture looks important without making every page a church bulletin.

---

## Inventory classes (from frozen manuscript)

| Class | Design treatment |
|---|---|
| INLINE_REFERENCE | Parenthetical/book-chapter-verse in body; same size; no bold spam |
| SHORT_QUOTATION | Inline quotes or short indented line; citation follows |
| FULL_VERSE | Scripture block (see grammar below) |
| MULTI_VERSE_PASSAGE | Scripture block with extra space above/below; protect from mid-passage page break when possible |
| KEY_DISCOVERY_PASSAGE | Scripture block + optional breathing room; rare soft emphasis (not a box by default) |
| GENESIS_REVELATION_CHAIN | Sequence of short blocks or inline landmarks; **timeline optional later** — default is prose/spaced blocks |
| COMPARATIVE_PASSAGE | Adjacent blocks or clear sequential blocks; avoid dual-column unless prototype proves clarity |
| MEMORY / REFLECTION VERSE | May appear in scarce reflection device; never worksheet “memorize!” chrome |
| SCRIPTURE_INSIDE_STORY | Remains in narrative voice; do **not** suddenly switch to liturgical display mid-scene (except brief citation) |

**Highest density chapters (need air):** ch06, ch01, ch04, ch08, ch09  
**Lowest:** ch00

## Scripture block grammar (RECOMMENDED)

```
[blank line / ~6–10 pt extra]
[indent ~1.5–2 × body indent OR hanging block indent]
[KJV text in body size or −0.5–1 pt; slightly increased leading]
[citation on own line or end of last line: Book ch:v, KJV]
[blank line]
```

| Parameter | Recommendation |
|---|---|
| Font | Same family as body **or** same family italic; avoid a costume “Bible font” |
| Size | Body or −0.5–1 pt (never tiny) |
| Leading | +1–2 pt vs body |
| Indent | Consistent book-wide |
| Verse numbers | Not required for continuous quotation; if present, small, unobtrusive |
| Quotation marks | Follow manuscript; do not double-decorate |
| Italics | Prefer for emphasis already in KJV italics policy; do not italicize whole blocks by default |
| Bold | **Almost never** inside Scripture text |
| Boxes | **Default OFF.** Reserve for rare KEY_DISCOVERY only if prototype needs it — prefer space over box |
| Rules | Optional hairline above/below for KEY_DISCOVERY only |
| Page breaks | Avoid orphan citation line; avoid splitting mid-sentence; multi-verse: keep at least 2 lines together |

## Hierarchy of visual strength

1. Inline reference — weakest  
2. Short quotation — light  
3. Full verse block — standard dignity  
4. Key discovery (Exod 34, Job 2:13, Phil 4 garrison, Heb 4:14–16, Lam 3) — space + optional hairline  
5. Boxed Scripture — **last resort**, Phase 2 only if space fails

---

## Genesis→Revelation presentation

- Keep “Line upon line — Genesis to Revelation” as a **section head**, not a stamped logo.
- Present landmarks as readable sequence with breathing room.
- Diagram/timeline: **candidate only** (see Diagram Strategy); not required for comprehension.

## Scripture inside grief (ch06)

- More space, not more chrome.
- Uncle’s quick “Romans 8:28” stays visually “small” (inline); Lena’s later long reading gets expanse — contrast is pastoral design.

## Anti-patterns

- Every verse in a shaded box  
- Gold filigree / cross ornaments on citations  
- Rainbow reference highlighting  
- Bolding half the verse  
- Callout titled “God’s Word for You!”  
- Parallel-column KJV vs paraphrase (no paraphrase authority)

## Success test

Reader feels: “The Scripture had room to breathe.”  
Not: “This page is a bulletin.”
