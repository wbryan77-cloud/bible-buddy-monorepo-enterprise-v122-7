# Volume 1 — Heading Hierarchy

**Date:** 2026-08-29  
**Problem:** Intentional house H2 furniture repeats across chapters. This is now primarily a **design** problem — not a rewrite mandate.

## Hierarchy levels (print)

| Level | Use |
|---|---|
| H1 | Chapter title only |
| H2 | Major section furniture |
| H3 | Sub-beats under Scripture stacks |
| Run-in bold | Rare; prefer true subheads |

## Variety without decoration

1. **Spacing:** alternate tighter/looser before repeated furniture across chapters.  
2. **Small caps** for repeated furniture to reduce “worksheet shout.”  
3. **Rules:** at most a hairline for G2R or Named frame — not every H2.  
4. **Suppression:** In Phase 2, trial **visual suppression** (same text, less prominence) — not deletion of manuscript headings without Founder text approval.  
5. **Page position:** avoid starting every spread with the same H2 family when possible via break choices.

## Do not

- Random ornaments per heading  
- Color-coding heading types  
- Icons for “Monday” / “Scripture” / “Warning”  
- Rewrite headings for novelty

## Success test

Repeated structure feels like a trustworthy house style — not a cloned template page.
