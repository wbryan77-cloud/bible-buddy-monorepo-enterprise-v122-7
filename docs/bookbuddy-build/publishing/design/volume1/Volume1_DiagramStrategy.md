# Volume 1 — Diagram Strategy

**Date:** 2026-08-29  
**Rule:** A diagram must explain faster or more clearly than prose. Benchmark books using diagrams is not sufficient reason.

---

## DIAGRAMS_NOT_WORTH_CREATING

- Full habit science loops mimicking *Atomic Habits* trade dress  
- Money pipeline infographics  
- Relationship decision trees with icons  
- Collage-god org chart  
- Companion volume product grid  
- “Seven benchmarks” anything  
- Character relationship maps  

## Style if approved

- Single-weight lines  
- Typography-led labels  
- Grayscale  
- No isometric / 3D / gradient  

## Success test

Diagram removable without loss of doctrine; present only for clarity speed.
