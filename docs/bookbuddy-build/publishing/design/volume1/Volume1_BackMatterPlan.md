# Volume 1 — Back Matter Plan

**Date:** 2026-08-29  
**Rule:** Literary ending of ch12 remains the emotional ending. Any next-book preview occurs **after** that ending — never inside it. No companion grid on last story spread.

---

## Proposed elements

| Element | Recommendation |
|---|---|
| Acknowledgments | FOUNDER_DECISION_REQUIRED |
| Notes / endnotes | RECOMMENDED if apparatus needed |
| Original-language source note | RECOMMENDED short (Nestle 1904 / OSHB / KJV statement) |
| Scripture index | OPTIONAL — valuable; production cost |
| Subject index | DEFER — optional later edition |
| Reflection resources | Soft no — avoid workbook appendix |
| Recommended Bible-reading path | OPTIONAL short; ch07 already teaches beginning |
| Series note | RECOMMENDED brief — architecture without hard sell |
| Next-book preview | OPTIONAL separable (`NextBookPreview_Optional.md` spirit) **after** emotional end |
| About author | FOUNDER_DECISION_REQUIRED — factual only; do not invent |
| Website / BibleBuddy connection | FOUNDER_DECISION_REQUIRED — one clean line max if any |

---

## Ending anatomy (design)

```
ch12 literary close (Monday Mercy / quiet presence)
→ optional blank
→ back matter begins
→ optional human series doorway note (C3 need surfaced without ad copy)
→ optional separable preview
```

## Anti-patterns

- Catalog of companions as last image  
- QR code sprawl  
- “Rate this book”  
- Fake reviews
