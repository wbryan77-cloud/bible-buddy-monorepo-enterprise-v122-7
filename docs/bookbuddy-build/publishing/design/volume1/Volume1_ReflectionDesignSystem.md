# Volume 1 — Reflection Design System

**Date:** 2026-08-29  
**Inputs:** `Volume1_DesignOpportunities.md` + independent manuscript audit  
**Rule:** Scarcity creates meaning. This is **not** a workbook.

---

## Device family (small — RECOMMENDED max 4 labels)

Candidates (human language; not all mandatory):

| Device | Function | Typical placement |
|---|---|---|
| **Pause** | Emotional/Scriptural breathing — often *no label*, just space | After disclosures; after key verses |
| **Consider** | One question for self-recognition | After crossroads lines (Ava, Helen) |
| **Pray honestly** | Short invitation to speak to God without performance | After Naomi/Camila prayer beats |
| **Try this** | Single concrete next step (overlaps Application system) | Near Monday sections — use sparingly |

**Rejected as default labels:** PAUSE HERE (too worksheet), LOOK AGAIN (optional later), WHAT DOES THIS REVEAL? (too study-guide), THIS WEEK (feels curriculum).

**RECOMMENDED default:** Most reflection is **typographic space + one quiet question**, not a labeled box.

## Frequency cap

| Unit | Max labeled reflection devices |
|---|---|
| Per chapter | **0–1** typical; **2** only if proven necessary |
| ch06 | **0 labeled boxes**; space only |
| Whole book | Prefer **< 12** labeled reflection instances total |

## Visual grammar for a rare reflection question

- Full measure or slight indent  
- One question  
- No checkbox  
- No “Journal here” lines  
- No icon  
- Optional light rule above — not a shaded panel

## Success test

Reader feels invited to think — not assigned homework.
