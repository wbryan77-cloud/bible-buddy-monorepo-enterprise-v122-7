# Volume 1 — Color Strategy

**Date:** 2026-08-29  
**Rule:** Book must be fully understandable in black-and-white. Color never carries essential meaning.

---

## PRINT-FIRST GRAYSCALE SYSTEM (default)

| Element | Treatment |
|---|---|
| Body | Black / near-black on white/off-white |
| Heads | Black |
| Rules | 20–40% gray hairlines |
| Tables | Hairline rules; optional 5–8% header tint max |
| Callouts | Left rule or light gray fill ≤8% |
| Scripture | No fill by default |
| Folios | Medium gray OK |

Paper: prefer warm-white trade stock over stark blue-white if print path allows (**EXTERNAL_VERIFICATION** with printer).

---

## OPTIONAL LIMITED-COLOR SYSTEM (later edition)

If Founder authorizes color interior:

| Role | Restraint |
|---|---|
| Accent | Single muted ink (deep olive, slate, or warm iron — **not** neon, not generic gold-religious luxury, not corporate blue everywhere) |
| Use | Chapter number, rare rule, series mark on half-title only |
| Never | Rainbow chapter coding; gradients; icon coloring; Scripture in accent ink as “holy highlighter” |

**Do NOT finalize brand colors in Phase 1.** Status: `DEFER_TO_COVER_PACKAGING` + Phase 2 grayscale prototypes first.

---

## Anti-patterns

- Chapter color themes  
- Gold foil mentality in interior  
- Heavy shaded boxes  
- Color-only hierarchy
